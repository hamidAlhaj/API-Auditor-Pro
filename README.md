# API-Auditor-Pro
API Auditor Pro: A comprehensive API security assessment system targeting OWASP API Top 10 vulnerabilities. Graduation project by Hamid Alhaj &amp; Wadie Alkhoury at AUST. Features AI-driven vulnerability analysis (DistilBERT), professional report generation  and a modern, responsive React &amp; TypeScript frontend with bilingual (AR/EN) support.
